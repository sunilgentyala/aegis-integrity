A Small Sample Manuscript for Verifying an AEGIS Install

Abstract
This short synthetic manuscript exists only so that new users can confirm that AEGIS runs on their machine within a minute of installing it. It was written for this repository and contains no third-party text, so it can be copied, edited, and redistributed without any licence concerns. It deliberately includes a handful of ordinary style slips, such as mixed British and American spelling, a contraction, a repeated word, and a sentence that opens with a numeral, so that the offline guideline scan has something concrete to report. The abstract is also sized to fall inside the range that several publishers request, which lets the abstract length check show a passing result next to the failing ones. The scientific content is intentionally empty: there is no real dataset, no experiment, and no claim of any kind, which keeps the file short enough to read in full before you run the tool on it.
